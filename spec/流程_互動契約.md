# 流程_互動契約(輸入空間表)

本檔為圖台互動之行為契約:由**系統輸入空間**(元素 × 事件 × 狀態,自源碼 grep 全範圍取得)笛卡兒積推導,每格填「應然」;現況與差異已於 2026-08-27 依此表修正並以測試鎖定.`流程_圖台互動.md` 之 E2E bullet 為本表之端對端抽樣.

## 1. 領域常規對標(動手前)

| 行為 | React Flow(Handle/ConnectionMode 文件) | draw.io | 本系統(修正後) |
|---|---|---|---|
| 自哪種把手可出發建線 | source 與 target 皆可(`isConnectableStart` 預設 true) | 任一連接點皆可 | **source 與 target 皆可** |
| 配對規則 | Strict:只允許 source↔target | 任意 | **Strict**:出發 source → 只能落他節點 target;出發 target → 只能落他節點 source |
| 自我連線 | 由 validator 決定 | 允許 | **禁止**(self) |
| 同類把手 | Strict 下 invalid | — | **禁止**(same-kind),游標 not-allowed |
| 建線中不可連落點 | invalid class | — | invalid ring + not-allowed |
| 一次一手勢 | 是(drag/connect/pan 互斥) | 是 | **activeGesture 單值** |
| 手勢開始關閉浮層 | 是 | 是 | **closeAllPopups()** |
| 拖曳中他元素 hover | 不反應 | 不反應 | **vue-flow--gesturing 抑制** |
| affordance 之點擊代表宿主 | 否 | 否 | **否**(節點/邊一致) |
| 主鍵限制 | 是 | 是 | 是(把手/四角/轉折點/畫布/節點皆 `button===0`) |

## 2. 軸與成員(自源碼取得)

- **可命中元素**(`closest('.vue-flow__*')` 全集 + overlay):`popup`(Teleport 至 body,不在 flow DOM 內)/`panel`(工具列)/`node-gear`(含 anchor)/`edge-gear`(含 anchor)/`resize`(四角)/`handle`(source|target)/`waypoint`/`edge`(線本體+label 區)/`node`(本體,含 dragHandle/互動元素/nodrag 區)/`canvas`.
- **輸入事件**:mousedown / mousemove / mouseup / click / dblclick / contextmenu / mouseenter-leave(hover)/ wheel / keydown.
- **滑鼠鍵**:主鍵 / 非主鍵.
- **activeGesture**(單值):`null | pan | drag | resize | connect | waypoint | boxselect`.
- **overlay**(可疊加):`popup-open`(至多一個)/`multiselect`(複選鍵生效).
- **能力旗標**:`locked` / `elementsSelectable` / `nodesConnectable` / `nodesDraggable` / `nodesResizable` / `settingsEnabled`.
- **終止路徑**:mouseup / window blur / buttons 復原(視窗外放開)/ 元件 destroy / `locked` 切換.

## 3. 基線表(activeGesture=null,無 overlay,能力全開)

| hit | mousedown(主鍵) | click | dblclick | contextmenu | hover | 非主鍵 mousedown |
|---|---|---|---|---|---|---|
| popup | 交給 popup(不進 flow) | — | — | — | — | — |
| panel | 無手勢;不關 popup 之外的副作用 | 工具列動作 | **不發 canvas-dblclick** | **不發 pane-context-menu** | 工具列自身 | 無 |
| node-gear | 無手勢(不拖不平移);冒泡至 window 關他 popup | 開設定 + activate(sole) | **不發 node-double-click** | **不發 node-context-menu** | 齒輪 hover;宿主節點同時 hovered | 無 |
| edge-gear | 同上 | 開設定 + activate | 不發 conn-double-click | 不發 conn-context-menu | 齒輪 hover(class 驅動);邊同時 hovered | 無 |
| resize | **resize 手勢** + activate + **closeAllPopups** | 無 | **不發** | **不發** | 四角 hover | **無**(button 守衛) |
| handle(source/target) | **connect 手勢**(雙向)+ closeAllPopups | 無(`.stop`) | **不發** | **不發** | 放大變藍(兩種把手皆真的可操作) | 無 |
| waypoint | **waypoint 手勢** + closeAllPopups | 無 | 不發 | 不發 | 轉折點 hover | **無** |
| edge(含 label) | **無手勢,不平移** | 選取 + info popup(hasInfoPopup 時)+ conn-click | conn-double-click | conn-context-menu | 線加深 + 齒輪出現 | 無 |
| node | drag 手勢(跨門檻)+ mousedown 選取 + 關自身 info popup;dragHandle/互動元素/nodrag 區不武裝拖曳 | node-click(+info popup 經 WPopup trigger) | node-double-click | node-context-menu | 陰影 + 齒輪 + 四角 | 無(不選取不拖) |
| canvas | 平移(panOnDrag);複選鍵 → 框選 | pane-click + 清選取 | canvas-dblclick | pane-context-menu | 無 | 無 |

規則:**affordance(gear/resize/handle/waypoint/panel)永不代表其宿主元素或畫布發 click 類事件**;每次 mousedown 至多啟動一個手勢.

## 4. 建線(connect)細則

- 出發:主鍵 + connectable + nodesConnectable + 未鎖定 + 非複選 + activeGesture=null.`connect-start.handleType ∈ 'source'|'target'`.
- 候選正規化:`from = source 端節點, to = target 端節點`;Fixed 錨點依端點各自烙印(`fromPosition` 來自 source 端把手,`toPosition` 來自 target 端把手),與出發方向無關.宿主 validator / `connect` 事件收到的形狀與單向時代完全相同.
- reason 優先序:`no-endpoint` → `unknown-handle`(型別非 source/target)→ `self`(同節點,任何把手)→ `same-kind`(他節點同類把手)→ `not-connectable` → 圖層級(`missing-node` → `from-output` → `to-input` → `duplicate` → `custom`).
- 游標/視覺(建線期間):畫布內一律 default;origin 與 valid → crosshair;invalid → not-allowed + danger ring;**出發節點之所有其他把手**(`data-connect-origin-node`)與**他節點之同類把手**(根 `data-connect-from=source|target`)→ 淡化 + not-allowed(不需 hover 判定即刻正確);他節點異類把手 hover → 即時 valid/invalid.
- 預覽線:依 `connectionVisual.originType` 以正規化後之 source/target 參數繪製(step/smoothstep/bezier 皆與最終邊同向);無 hover 時遠端方位預設:source-origin → 'top',target-origin → 'bottom'.
- `not-connectable` 把手 `pointer-events:none`,真實滑鼠 hit 不到(設計限制:不可連即無 affordance);該 reason 僅程式化路徑可達.

## 5. 手勢生命週期(所有手勢一致)

| 階段 | 規則 |
|---|---|
| 啟動 | `activeGesture===null` 才可;啟動即 `closeAllPopups()`;根 class `vue-flow--gesturing`;手勢擁有者元素標 `data-gesture-owner` |
| 進行 | 非擁有者元素之 hover affordance(節點陰影/齒輪/四角、邊加深/齒輪/轉折點)抑制;`canOpenPopup()` 為 false(含公開 API `openNodeInfoPopup` / `openConnInfoPopup` 與 `panToNode({openPopup})` 之延遲開啟) |
| 終止 | mouseup / blur / buttons 復原 / destroy / 上鎖切換 → 同一收尾:清 activeGesture、根 class、owner 標記、各手勢暫態;connect 額外清 `data-connect-*` |
| 上鎖切換 | 進入 locked 時:connect / boxselect / pan 取消;drag / resize / waypoint **取消提交**(ghost 復原,不寫回,不發 update) |

## 6. overlay 規則

- **popup-open**:同 flow 至多一個(WPopup 之 window mousedown 互斥 + 本系統對 `.stop` 路徑之 `closeAllPopups` 補強);任何手勢啟動關閉全部;popup 內 wheel/鍵盤屬 WPopup 範疇(Teleport).鍵盤 Delete 於 input/textarea/select/contenteditable/**button** 上不觸發畫布刪除.
- **multiselect**:隱藏全部 affordance;拒開任何 popup;節點 click=toggle;邊 click 不變更選取只發事件;dblclick/contextmenu **仍發**(資訊事件,刻意允許);hover 陰影/邊加深**仍在**(被動視覺,刻意允許);不得啟動 resize/connect/waypoint;建線進行中按住複選鍵建線續行.

## 7. 能力旗標(靜態,只擋啟動,不擋資訊事件與被動視覺)

| 旗標 | 擋 | 不擋(刻意允許) |
|---|---|---|
| locked | drag/resize/connect/waypoint 啟動;齒輪/四角/把手/轉折點隱藏 | 選取、info popup、click/dbl/context 事件、hover 陰影、平移縮放 |
| elementsSelectable=false | 選取/activate;popup 之 elementsSelectable 無關(仍可開) | 事件照發 |
| nodesConnectable=false / node.connectable=false | 建線啟動與落點 | 把手仍顯示(pointer-events none) |
| nodesDraggable=false / node.draggable=false | 拖曳 | 選取、事件 |
| settingsEnabled=false | 齒輪/轉折點 | — |

## 8. 已知不修 / 設計限制

- popup 內滾輪不縮放 flow(Teleport overlay,WPopup 範疇).
- `not-connectable` 把手無 hover 回饋(pointer-events none,見 §4).
- 同頁多實例按住複選鍵同時進入模式(全域行為,刻意).
